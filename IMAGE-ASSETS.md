# Loleza Ridge visual assets

The landing page now uses locally bundled, optimized WebP lodge visuals instead of the placeholder SVG illustrations that were previously shown on mobile.

The image set is designed around the Loleza Ridge visual direction: Southern Highlands lodge architecture, warm interiors, coffee, mountain views, dining, evening fires and nature.

The current visuals are presentation assets generated for the website concept. For a real lodge launch, replace them with the property's own licensed photography so the images accurately represent the actual rooms, grounds, food and views.
