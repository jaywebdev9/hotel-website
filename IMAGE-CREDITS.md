# Image sources used in the visual upgrade

The visual upgrade uses locally downloaded and WebP-optimized reference photography so the site no longer depends on the original demo SVG artwork for its main visual sections.

- `mbeya-landscape.webp` — Lunji Coffee Farm / Mbeya landscape, sourced from We Travel.
- `coffee-estate.webp` — Lunji Coffee Farm / Mbeya coffee estate, sourced from We Travel.
- `lodge-exterior.webp` — Mountain lodge exterior reference, sourced from Mvuli Mountain Lodge coverage.
- `room-luxury.webp` — Tanzanian safari-lodge interior reference.
- `breakfast.webp` — Tanzanian safari-lodge breakfast reference.
- `dining-view.webp` — Tanzania lodge terrace dining reference.
- `pool-view.webp` — Tanzania lodge pool / mountain-view reference.

Before public commercial deployment, replace third-party reference photography with images owned by Loleza Ridge Lodge or images for which the lodge has an appropriate commercial license. The files in this project have been resized and converted to WebP for faster delivery.
